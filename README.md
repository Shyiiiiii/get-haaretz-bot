# בוט מחירון וואטסאפ — Get הארץ

בוט שמקבל הודעת וואטסאפ עם **מוצא ויעד** ומחזיר **הערכת מחיר**.
מבין את שפת השוק האמיתית: גם "מתל אביב לירושלים", גם קיצורים כמו **"בב פת"** (בני ברק → פתח תקווה) ו-**"ים שמש הלוך חזור"**.

---

## מודל התמחור — הכי חשוב

הבוט תומך בשלושה מודלים (נקבע ב-`src/pricing.js` → `PRICING_MODE`):

| מודל | איך מתמחר |
|------|-----------|
| **`hybrid`** (ברירת מחדל) | מחיר שוק אמיתי אם המסלול מוכר, אחרת נופל לחישוב ק"מ×4 |
| `market` | רק מחירי שוק (מסלול לא מוכר → מפנה לתיאום טלפוני) |
| `km` | תמיד ק"מ × 4₪ |

**למה hybrid?** ניתוח של 173 הצעות אמיתיות מחדרי הסדרנים הראה שמחירי השוק
**לא** הולכים לפי ק"מ: ת"א→בני ברק = 100₪ (ק"מ×4 ≈ 32₪), ירושלים→ת"א = 150₪
(ק"מ×4 ≈ 260₪). נוסחת ק"מ בלבד מתמחרת שגוי. המודל ההיברידי נותן מחיר שוק
מדויק במסלולים המוכרים, ונוסחת ק"מ ככיסוי לכל השאר.

## מחירים ידניים (שלך) — עדיפות עליונה

`data/manual-prices.json` הוא המחירון **שאתה** קובע. הוא גובר על טבלת השוק.
תומך גם בדיוק **שכונתי** בירושלים:

```json
{
  "routes": {
    "בית שמש → ירושלים": 150
  },
  "neighborhoodOverrides": {
    "בית שמש → ירושלים": { "רמות": 170, "נווה יעקב": 170 }
  }
}
```

- כל מסלול **סימטרי** — נתפס בשני הכיוונים.
- לקוח ששולח "מבית שמש לרמות" יקבל 170; "מבית שמש לירושלים" יקבל 150.
- שכונות ירושלים מזוהות אוטומטית (רשימה ב-`src/places.js`).
- **סדר עדיפות התמחור:** ידני → שוק → ק"מ.

## בניית טבלת מחירי השוק

מייצוא צ'אט וואטסאפ של קבוצת סדרנים:

```bash
node tools/build-market.js "נתיב/ל/_chat.txt"
```

מחלץ כותרות הצעה (`*מסלול מחיר*`), מנרמל קיצורים, ומחשב **מחיר מודוס**
לכל מסלול (השכיח — לא ממוצע), עם ספירת דגימות. רק מסלולים עם ≥2 דגימות
נחשבים "בטוחים". ריצה מחדש מעדכנת מחירים ככל שנכנסים צ'אטים חדשים.

## שינוי תעריפים

הכול ב-`src/pricing.js`:
```js
PRICING_MODE: 'hybrid',   // 'hybrid' | 'market' | 'km'
RATE_PER_KM: 4,           // ₪ לק"מ (נפילה)
MINIMUM_FARE: 0,          // מחיר מינימום
ROUND_TRIP_DISCOUNT: 0,   // הנחת הלו"ש (בעבר 20)
MARKET_MIN_COUNT: 2,      // מינ' דגימות למחיר שוק "בטוח"
```

הוספת קיצורי מקומות: `src/places.js`.

## הקמה מלאה — 4 שלבים

**1. מפתח Google Maps** — [Cloud Console](https://console.cloud.google.com/) →
פרויקט → הפעלת **Distance Matrix API** → יצירת API Key → ל-`GOOGLE_MAPS_API_KEY`.
(נדרש רק אם משתמשים ב-`hybrid`/`km`.)

**2. WhatsApp Cloud API** — [developers.facebook.com](https://developers.facebook.com/) →
Create App (Business) → הוספת מוצר WhatsApp → העתקת **access token** ל-`WHATSAPP_TOKEN`
ו-**Phone number ID** ל-`WHATSAPP_PHONE_NUMBER_ID`. `VERIFY_TOKEN` = מחרוזת סודית משלכם.

**3. פריסה** — העלאה ל-GitHub → [Render](https://render.com/) New Web Service
(Build: `npm install`, Start: `npm start`) + הזנת משתני הסביבה. לבדיקה מקומית: `ngrok http 3000`.

**4. חיבור Webhook ב-Meta** — Configuration → Webhook:
Callback URL = `https://הכתובת/webhook`, Verify token = ה-`VERIFY_TOKEN`,
סימון שדה **messages**.
