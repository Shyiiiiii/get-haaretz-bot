# Get הארץ — בוט מחירון וכלי תמחור

שני כלים שחולקים את אותו מנוע מחירים:

1. **בוט וואטסאפ** — הלקוח שולח "מבית שמש לירושלים", מקבל הצעת מחיר מיידית.
2. **מחירון** (`מחירון-Get-הארץ.html`) — כלי חיפוש מהיר לשימושך, עובד גם בלי אינטרנט.

---

## מנוע התמחור — פשוט

כל הכללים רצים **פעם אחת בבנייה** ומייצרים טבלה אחת: `data/prices.json`.
הבוט פשוט קורא ממנה. בלי חישובים בזמן אמת.

```bash
npm run build    # בונה את הטבלה + את המחירון
```

**סדר עדיפויות בבנייה:**
```
1. המחירון שלך (manual-prices.json)  ← גובר על הכול
2. מחירונים מפורסמים
3. מחירי שוק — רק עם ≥3 דגימות ו-≥40% הסכמה
```
פער כיווני >50% → נבחר המחיר הגבוה (הגנה מתמחור בחסר).
מסלול בלי מחיר מאומת → *"מחיר אישי"* + הפניה לטלפון.

## עריכת מחירים

`data/manual-prices.json`:
```json
{
  "routes": { "בית שמש → ירושלים": 150 },
  "neighborhoodOverrides": {
    "בית שמש → ירושלים": { "רמות": 170 }
  },
  "excluded": ["גבעת זאב → ירושלים"]
}
```

- **routes** — מחיר קבוע (סימטרי, שני הכיוונים)
- **neighborhoodOverrides** — תעריף שכונתי בירושלים
- **excluded** — מסלול שלא יתומחר כלל (הפניה לתיאום אישי)

השינויים שורדים בנייה מחדש של טבלת השוק.
אפשר גם לערוך דרך לוח הניהול: `/admin?pass=...`

## הלו״ש (הלוך-חזור)

```
מחיר הלו״ש = מחיר כיוון אחד × 2 − 40₪
```
כולל **המתנה של עד שעה** ביעד. מוגדר ב-`src/pricing.js` → `ROUND_TRIP_DISCOUNT`.

דוגמה: בית שמש ↔ ירושלים = 150₪ → הלו״ש **260₪**.
